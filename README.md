# گاهشمار خورشیدی | Persian Calendar

**این اپ بر خلاف تقویم‌های شلوغ ایرانی، در ساده‌ترین حالت ممکن برای نیاز شخصی طراحی شده است.**

## ویژگی‌ها

- گاهشمار شمسی و میلادی
- طراحی چشم‌نواز تقویم سامسونگ
- تعطیلات رسمی ایران فقط با درج رنگ قرمز
- امکان ثبت رویداد با قابلیت تکرار هفتگی، ماهانه و سالانه
- امکان محاسبه فاصله دو روز دلخواه بر حسب روز عادی و روز کاری (با لمس طولانی روز مبدأ و مقصد)
- **رایگان** و بدون تبلیغ

## محدودیت‌ها

- سینک با گوگل ندارد
- رویدادها فقط به صورت متن ذخیره و بازیابی می‌شوند
